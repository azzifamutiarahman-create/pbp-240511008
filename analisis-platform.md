# Analisis Komparatif Platform: Web, Desktop, dan Mobile

Berikut adalah tabel analisis komparatif yang membandingkan platform Web, Desktop, dan Mobile berdasarkan berbagai aspek teknis dan fungsional.

## Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML, CSS, JavaScript (TypeScript) | C#, C++, JavaScript/TypeScript (Electron), Swift | Kotlin, Java (Android), Swift, Objective-C (iOS) |
| **Arsitektur** | Client-Server (Browser-based, SPA/MPA) | Native Application / Hybrid Client-Side Architecture | Native Application (Activity/Fragment di Android, ViewController di iOS) |
| **Cara distribusi** | Web Hosting (CDN, Vercel, Netlify, Server mandiri) | Installer terdedikasi (.exe, .dmg, .deb, Microsoft Store, App Store) | Official App Store (Google Play Store, Apple App Store) |
| **Keunggulan** | • Tidak perlu instalasi (akses via browser)<br>• Mudah diperbarui secara real-time<br>• Jangkauan lintas platform yang sangat luas | • Performa tinggi dan akses penuh ke hardware lokal<br>• Dapat berjalan secara offline dengan stabil<br>• Cocok untuk komputasi berat | • Integrasi mendalam dengan fitur perangkat (Kamera, GPS, Biometrik)<br>• Mobilitas tinggi dan penggunaan notifikasi push yang masif |
| **Keterbatasan** | • Ketergantungan penuh pada koneksi internet<br>• Akses terbatas ke hardware perangkat keras (tergantung browser)<br>• Variasi kompatibilitas antar browser | • Proses instalasi dan pembaruan aplikasi relatif lebih lama<br>• Ukuran file instalasi cenderung besar<br>• Terikat pada sistem operasi tertentu (OS-dependent) | • Keterbatasan ukuran layar<br>• Fragmentasi perangkat (terutama Android)<br>• Proses peninjauan (review) ketat sebelum rilis di app store |
| **Contoh aplikasi** | Google Docs, Trello, Netflix (Web version) | Microsoft Office, Adobe Photoshop, VS Code | WhatsApp, Instagram, Mobile Banking (BCA Mobile) |
